# 用一台境内的家用电脑做回国出口

**政务网站 11 秒超时打不开 → 0.61 秒。成本零。**

**方向的唯一正确读法**：使用者在**境外**，出口在**境内**。
服务端装在**境内**那台（它的住宅 IP 就是出口），客户端装在**境外**这台。

两台都是普通家用宽带，不租服务器、不买专线、不走商业加速器。

## 它是什么，不是什么

**不是**一个软件、一个服务、或一套订阅。仓库里没有任何可用的默认节点。

**是**一套方案：给「境外有个愿意帮你、且机器能长期开着的人」的人，一套能落地的方法。

**它不适合：**

- 对方电脑不能长期开机
- 你需要 7×24 可用
- 你只是想看视频刷社交
- 你不想折腾

**它适合：**

- 需要访问对机房 IP 有额外风控的站点
- 境外有信任的人，机器能长期开着
- 愿意花半天部署，能自己排查

---

## 一句话

这套东西用「可用性」和「省心程度」，换「住宅 IP + 零成本 + 数据只经过你们两台机器」。

如果你不需要住宅 IP，商业方案更省事——这不是客套话。
