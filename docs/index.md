# 用一台家用电脑做「双向」住宅出口

**政务网站 11 秒超时打不开 → 0.61 秒。成本零。**

这套方案不是「一条隧道」，是**两台机器互为出口**。境内那台给境外的你当回国出口；
反过来，境外那台也能给境内的你当出国出口。

| | **A 方向：回国** | **B 方向：出国** |
| --- | --- | --- |
| 使用者人在 | **境外** | **境内** |
| 出口在 | 境内（境内那台的住宅 IP） | 境外（境外那台的住宅 IP） |
| 服务端装在哪 | 境内那台 | 境外那台 |
| 解决什么 | 政务/银行/票务打不开、视频卡 | 需要海外住宅 IP 的注册验证、分区内容、价格查询 |

> **两个方向的上限各算各的，实测差 13 倍，不可互相换算。**

两端都是普通家用宽带，不租服务器、不买专线、不走商业加速器。

## 它是什么，不是什么

**不是**一个软件、一个服务、或一套订阅。仓库里没有任何可用的默认节点。

**是**一套方案：给「另一头有个愿意帮你、且机器能长期开着的人」的人，一套能落地的方法。

**它不适合：**

- 对方电脑不能长期开机
- 你需要 7×24 可用
- 你只是想看视频刷社交
- 你不想折腾

**它适合：**

- 需要访问对机房 IP 有额外风控的站点
- 另一头有信任的人，机器能长期开着
- 愿意花半天部署，能自己排查

## 一句话

这套东西用「可用性」和「省心程度」，换「住宅 IP + 零成本 + 数据只经过你们两台机器」。

**真正的稀缺不是技术，是那个愿意让你在他电脑上装东西的人。**
